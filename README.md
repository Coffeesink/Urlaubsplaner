# Urlaubsplaner

Webapp zum Planen der Urlaubsverteilung in einem Team. Einzelne Datei ohne Build: `index.html` im Browser öffnen.

- Teammitglieder mit Stellenfaktor, Urlaubswünsche als Datumsbereiche
- Einstellungen: Planungsjahr, Feiertage, Farbcodierung
- Auswertung: Kompakt (Kalender) und Details (Tabelle), druckbar
- Daten liegen im Browser (localStorage); Export/Import als JSON unter Einstellungen
